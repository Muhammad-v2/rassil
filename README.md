# Session Manager Bot + Mini App

Панель управления вашими Telegram-аккаунтами: список активных сессий с завершением
любой из них, отправка сообщений, редактирование профиля (имя/username/фото),
отложенные и повторяющиеся рассылки по выбранным чатам, уведомления о новых входах,
мультиаккаунтность. Весь интерфейс — Telegram Mini App (веб-панель внутри бота).

## Структура проекта

```
bot.py              — aiogram-бот: /start открывает Mini App, команды admin/addadmin/deladmin
web_app.py           — aiohttp-сервер с REST API для Mini App (вся основная логика)
userbot.py           — обёртка над Pyrogram: сессии, профиль, диалоги, отправка сообщений
scheduler.py         — APScheduler: рассылки по расписанию + мониторинг новых сессий
db.py                — Neon Postgres: аккаунты, админы, чаты, расписание, лог сессий
static/index.html    — сама Mini App (HTML/CSS/JS, без сборки, открывается как есть)
requirements.txt, Procfile, .env.example
```

## Шаг 1 — подготовка ключей

1. **API_ID / API_HASH** — https://my.telegram.org → API development tools
2. **BOT_TOKEN** — создайте бота через @BotFather (`/newbot`)
3. **Ваш Telegram ID** — узнать у @userinfobot
4. **DATABASE_URL** — https://neon.tech → создать проект → скопировать Connection string
   (обязательно с `?sslmode=require` на конце)

## Шаг 2 — загрузка на GitHub

Создайте новый репозиторий на GitHub → Add file → Upload files → загрузите **все файлы
и папку `static/` целиком** (со всей вложенностью — GitHub веб-интерфейс поддерживает
drag-n-drop папок).

## Шаг 3 — деплой на Railway

1. https://railway.app → New Project → Deploy from GitHub repo → выберите репозиторий
2. Дождитесь первого (упадёт с ошибкой — это нормально, WEBAPP_URL ещё не задан)
3. Откройте вкладку **Settings → Networking → Generate Domain** — Railway выдаст адрес
   вида `https://your-app-name.up.railway.app`
4. Откройте вкладку **Variables** и добавьте:
   - `BOT_TOKEN`
   - `API_ID`
   - `API_HASH`
   - `ADMIN_IDS` — ваш ID (и через запятую ID доверенных людей, если хотите сразу)
   - `DATABASE_URL`
   - `WEBAPP_URL` — тот адрес, что выдал Railway на шаге 3 (обязательно с `https://`)
5. Railway автоматически передеплоит сервис после сохранения переменных

## Шаг 4 — подключение Mini App в BotFather

Чтобы кнопка красиво открывалась и (по желанию) через меню бота:
1. @BotFather → `/mybots` → выберите бота → Bot Settings → Menu Button
2. Укажите тот же `WEBAPP_URL`

## Шаг 5 — первый запуск

1. Откройте бота, нажмите `/start`
2. Нажмите «🎛 Открыть панель управления»
3. В панели: «➕ Добавить аккаунт» → два способа на выбор:
   - **📁 .session файл** — загрузить готовый файл (как раньше)
   - **📱 Вход по номеру** — прямо в панели: номер телефона → код, который придёт вам в
     Telegram/SMS → (если включена 2FA) облачный пароль. Ничего вручную в Termux писать
     не нужно — весь процесс идёт через кнопки.

### Как получить .session файл вручную (альтернатива входу по номеру)

Если ещё не создавали — на своём компьютере (одноразово, локально):
```bash
pip install pyrogram tgcrypto
python3 -c "from pyrogram import Client; Client('myaccount', api_id=ВАШ_API_ID, api_hash='ВАШ_API_HASH').run()"
```
Введёте номер телефона и код — появится файл `myaccount.session` в этой же папке.
Именно его и загружайте в Mini App.

## Что внутри панели

- **📱 Мультиаккаунтность** — сколько угодно аккаунтов, переключение между ними одной кнопкой,
  у каждого видно телефон/username/ID
- **📋 Сессии** — устройство, платформа, страна/регион, IP, последний онлайн; кнопка
  завершения любой сессии, кроме текущей (текущая — та, через которую сам бот работает
  с этим `.session` файлом)
- **📊 Все сессии** (с главного экрана) — сводный last-active список по всем аккаунтам сразу
- **✉️ Сообщения** — выбор чата из подгруженного списка диалогов (личные/группы), текст
- **👤 Профиль** — имя, фамилия, username, загрузка/удаление фото профиля
- **⏰ Расписание** — выбираете чаты, текст, время первой отправки и (опционально) интервал
  повтора в минутах — например «каждые 50 минут» будет слать это же сообщение в выбранные
  чаты без вашего участия, пока не нажмёте «Отменить»
- **🔔 Уведомления** — бот сам раз в 5 минут проверяет все аккаунты; если появляется сессия,
  которой раньше не было, — присылает вам сообщение с устройством/страной/IP

## Команды бота (дублируют часть функций админки)

- `/start` — открыть панель
- `/admins` — список админов
- `/addadmin <id>` — добавить доверенного человека (то же можно в разделе «👥 Админы» в панели)
- `/deladmin <id>` — удалить админа (супер-админов из `ADMIN_IDS` удалить нельзя)

## Важные технические моменты

- **Session-конфликты**: один и тот же `.session` файл нельзя параллельно использовать
  в двух местах (например, у вас открыт локальный скрипт и одновременно панель дёргает
  тот же файл) — Telegram может сбросить сессию. Используйте файл только в одном месте.
- **Хранение сессий**: `.session` хранится в Neon Postgres как bytea, а не на диске
  Railway — при редеплое/рестарте ничего не потеряется.
- **Удаление аккаунта из панели** (кнопка 🗑) убирает только запись в БД бота — саму
  Telegram-сессию это не завершает. Чтобы разлогинить устройство/приложение — используйте
  раздел «Сессии» и завершайте именно ту сессию.
- **Повторяющиеся рассылки — по вашему собственному списку чатов, не массово**: интервал
  можно ставить любой, но учтите, что частая одинаковая отправка в несколько разных чатов —
  это в целом паттерн, который Telegram может расценить как автоматическую активность и
  ограничить аккаунт. Чем реже интервал и чем меньше разных получателей — тем безопаснее.
